# .github

늘빛 조직의 공개 공통 안내와 기본 템플릿을 관리합니다.

## PR 템플릿

[공통 PR 템플릿](.github/pull_request_template.md)은 목적과 변화, 검증 근거, 남은 문제와 다음 행동을 짧게 기록하도록 돕습니다. 작은 변경은 한두 문장으로 작성하고 해당 없는 항목은 삭제합니다. 관련 작업의 관계와 적용·복구 영향은 필요한 경우만 남깁니다.

이 저장소의 기본 브랜치에 반영되면 자체 PR 템플릿이 없는 조직 저장소의 새 PR에서 기본값으로 사용됩니다. 대상 저장소는 공개·비공개 모두 해당합니다. 저장소별 템플릿이 있으면 해당 템플릿이 우선하므로, 공통 양식을 사용하려면 기존 양식과 비교한 뒤 별도로 정리해야 합니다.

기존 PR 본문은 자동 변경되지 않습니다. 템플릿은 작성 안내이며 필수 입력 검사, 실행 권한 부여, 병합 승인이나 의존성 차단을 수행하지 않습니다.

이곳에는 공개 가능한 일반 양식만 둡니다. 내부 정책·운영 설정·업무 자료·실행 증거는 각 비공개 원본에 유지합니다.

참고: [GitHub 조직 기본 파일의 적용 규칙](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
